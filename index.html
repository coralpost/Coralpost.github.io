Scheduling short videos, quietly.

Coralpost is a small private desktop tool that a single creator uses to upload and schedule short videos to their own channels, and to read back basic performance numbers for those videos.

What it does

  • Uploads a finished video file to a channel the owner has authorised, as private with a scheduled publish time.
  • Sets the title and description the owner has written.
  • Reads view counts and simple analytics for the owner's own videos, so they can see what works.

What it does not do

It does not comment, like, subscribe, message other users or touch any channel the owner has not signed in with. It is not offered to the public and has no user accounts of its own.

Coralpost uses YouTube API Services. See the privacy policy and terms of use.

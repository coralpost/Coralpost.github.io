Privacy policy

Effective 2 November 2026

Coralpost is a private tool run by one person for their own channels. This page explains what data it touches and why.

Google and YouTube data

When the owner signs in with Google, Coralpost receives an access token for the channel they choose. It uses YouTube API Services to upload videos, set titles, descriptions and publish times, and read view and analytics figures for that channel's own videos. Coralpost's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage

Tokens and the numbers read back are stored only on the owner's own computer. Nothing is sold, shared with third parties, or used for advertising. No data about other YouTube users is collected.

Revoking access

Access can be withdrawn at any time from the Google security settings page at myaccount.google.com/permissions. Revoking access stops Coralpost from using the channel immediately; locally stored tokens are then deleted.

Third-party policies

By using Coralpost you are also bound by the YouTube Terms of Service and the Google Privacy Policy.

Changes

If this policy changes, the date at the top of this page is updated.
